# Carousel Performance Memory

Store what worked and what underperformed for each page/account.

Recommended files:

```text
<account>-winners.md
<account>-weak-formats.md
```

Track:

- Date
- Platform
- Topic
- Format
- Hook style
- Slide count
- CTA
- Performance signal
- What to repeat or avoid

Do not invent performance data. Add only observed results or user-provided notes.
