# Premium Clean Style

## Use When

The page needs polished, trustworthy, professional carousel visuals.

## Rules

- Restrained palette with one accent color.
- Generous safe margins.
- Large headline, short body.
- Minimal decorative elements.
- Consistent footer/handle placement.

## Avoid

- Excess gradients.
- Busy backgrounds behind text.
- Trendy effects that reduce readability.
