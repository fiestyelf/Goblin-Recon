# Facebook Image Specs

## Canvas
- Default export: 1200 x 628 px landscape.
- Safe zone: keep key text 72 px from every edge.
- Works for feed posts, link-style graphics, and page updates.

## Layout Rules
- Make the headline short enough to scan in-feed.
- Use more horizontal breathing room than Instagram.
- Keep the focal point off-center so text has a clean area.
- Prefer proof, context, and practical takeaways over mystery hooks.

## Caption Rules
- Lead with the practical reason the post matters.
- Keep copy direct, grounded, and human.
- Avoid hype, corporate filler, and fake urgency from `config/brand-voice.yaml`.
