# Instagram Carousel Specs

## Canvas
- Default export: 1080 x 1080 px square.
- Safe zone: keep key text 96 px from every edge.
- Preferred slide count: 5-8 slides for education, 1 slide for quote or announcement.

## Layout Rules
- Hook slide must be readable in under 2 seconds.
- Use one idea per slide.
- Keep body copy under 28 words per slide.
- Use strong contrast between text and background.

## Caption Rules
- Start with the same core tension as the hook slide.
- Keep brand-facing copy English-only.
- Avoid blacklisted hype, woo, consultant filler, and fake urgency from `config/brand-voice.yaml`.
- End with a simple next action, not a manipulative urgency line.
