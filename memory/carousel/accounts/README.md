# Carousel Account Memory

Create one file per page/account.

Recommended naming:

```text
<platform>-<page-slug>.md
```

Each account file should include:

- Page/account purpose
- Audience
- Voice rules
- Visual rules
- CTA preferences
- Claims to avoid
- Required logo/handle rules
- Known winners or weak formats

Page/account memory takes priority over brand, platform, trend, style, and performance memory.
