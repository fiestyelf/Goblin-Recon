# Facebook Carousel Trends

Use this file to record current Facebook image post and carousel-style patterns worth adapting.

## Current Patterns

- Clear educational or community-friendly framing.
- Slightly more context than Instagram, but still short enough for mobile.
- Direct CTA that fits page intent.
- Familiar visual hierarchy over experimental layouts.

## Avoid

- Clickbait claims.
- Overloaded slide text.
- Unsupported business or transformation promises.
