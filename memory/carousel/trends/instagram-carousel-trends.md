# Instagram Carousel Trends

Use this file to record current Instagram carousel patterns that are worth adapting.

## Current Patterns

- Strong first-slide hook with one clear promise or tension.
- Low text density per slide for mobile readability.
- Visual continuity across slides through repeated color, shape, or layout rhythm.
- Final slide uses one clear CTA.

## Avoid

- Copying creator content or claims from references.
- Dense paragraphs.
- AI-generated final text inside images.
